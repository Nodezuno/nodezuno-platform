# Nodezuno social logo pack

These files use the same four-node mark and colors as Nodezuno.com. The PNG files are ready for social platforms. Keep the supplied proportions and clear space.

## Start here

| Use | Recommended file |
| --- | --- |
| X, LinkedIn, Discord, Telegram, or other profile image | `png/profile/nodezuno-profile-on-ink-1024.png` |
| Profile image on a light brand field | `png/profile/nodezuno-profile-on-paper-1024.png` |
| Horizontal logo on a dark field | `png/wordmark/nodezuno-wordmark-on-ink-1840x448.png` |
| Horizontal logo on a light field | `png/wordmark/nodezuno-wordmark-on-paper-1840x448.png` |
| Logo over dark photography | `png/wordmark/nodezuno-wordmark-paper-transparent-1840x448.png` |
| Logo over light photography | `png/wordmark/nodezuno-wordmark-ink-transparent-1840x448.png` |
| Designer or vector workflow | A matching file in `svg/` |

Use the 1024 profile image unless a platform requires a smaller file. The 512 and 400 versions are included for strict upload limits. Profile artwork keeps the complete mark inside the circular-crop safe area.

## Variants

- `on-ink`: primary Nodezuno presentation on `#070908`.
- `on-paper`: high-contrast presentation on `#F2F1E9`.
- `paper-transparent`: light single-color artwork for a dark image or field.
- `ink-transparent`: dark single-color artwork for a light image or field.
- `gradient-transparent`: primary gradient symbol for a plain dark field only.

Transparent artwork can become unreadable on a similar color. Preview the actual platform crop and background before publishing.

## Usage rules

- Use the standalone mark for profile images. Do not squeeze the horizontal wordmark into a square avatar.
- Always capitalize the company name as `Nodezuno` in wordmarks and written copy.
- Do not stretch, rotate, redraw, retype, recolor, outline, shadow, or separate the mark and wordmark.
- Do not crop inside the supplied canvas.
- Keep clear space around externally placed artwork equal to at least one terminal node diameter.
- Use the standalone mark at 32 pixels or larger. Use the horizontal wordmark at 140 pixels wide or larger.
- At 16 pixels, use the website favicon rather than shrinking these social files.
- Do not use the logo to imply a customer, partner, investor, chain, or protocol endorsement.
